## AlmaLinux images

in `AlmaLinuxImages/`

cd ~/AlmaLinuxImages

1. verify disk device location (name, number)
check the dev name with `diskutil list`

2. unmount the device
sudo diskutil unmountDisk /dev/disk4

3. flash the device (this is almalinux 9.5)
sudo gdd of=/dev/rdisk4 if=AlmaLinux-9-latest-x86_64-dvd.iso status=progress bs=16M
sudo gdd of=/dev/rdisk4 if=AlmaLinux-9.6-x86_64-dvd.iso status=progress bs=16M
sudo gdd of=/dev/rdisk4 if=AlmaLinux-10.0-x86_64_v2-dvd.iso status=progress bs=16M

4. eject
sudo diskutil eject /dev/rdiskN
sudo diskutil eject /dev/rdisk4
