## Add permissions for uio and i2c access (solution from Jon)

```
sudo groupadd uiousr
sudo groupadd i2c
sudo usermod -a -G uiousr HGCAL_dev
sudo usermod -a -G i2c HGCAL_dev
```

Add a file /etc/udev/rules.d/99-uio.rules with the contents
```
SUBSYSTEM=="uio", GROUP="uiousr", MODE="660"
```

Add a file /etc/udev/rules.d/99-i2c.rules with the contents
```
SUBSYSTEM=="i2c-dev",KERNEL=="i2c-[0-9]*", GROUP="i2c", MODE="0660"
```

also added:

Add a file /lib/modprobe.d/uio_pdrv_genirq.conf with the contents
```
options uio_pdrv_genirq of_id="linux,uio-pdrv-genirq"
```

Add a file /lib/modprobe.d/i2c-xiic.conf with the contents
```
options i2c-xiic of_id="xlnx,xps-iic-2.00.a"
```
